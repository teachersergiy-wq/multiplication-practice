# Навчальна студія

Навчальна платформа для створення, призначення та проходження тестів із різних предметів і для різних класів. Тренажер множення — перший предметний модуль загального тестового рушія.

## Стан

- **PARTIAL:** responsive React/TypeScript оболонка бібліотеки та конструктора тестових чернеток.
- **VERIFIED:** окремий Supabase проєкт створений; міграції моделі, RLS для answer key і замороження опублікованих тестів застосовані.
- **PLANNED:** вхід, синхронізація, авторський редактор запитань, призначення класу, учнівські спроби й серверна перевірка.
- Локальні чернетки зберігаються в браузері, доки не підключено облікові записи й API.

## Розробка

1. Встановіть Node.js LTS.
2. Запустіть `npm install`.
3. Скопіюйте `.env.example` у `.env.local`, додайте URL проєкту й publishable key.
4. Запустіть `npm run dev`.

Фронтенд: React, TypeScript, Vite. Backend: Supabase Auth + Postgres/RLS + Edge Functions. Service role key заборонено додавати у фронтенд або репозиторій.

## Структура

- `src/domain.ts` — спільні типи й початковий каталог предметів.
- `src/App.tsx`, `src/styles.css` — UI бібліотеки та чернеток.
- `supabase/migrations/` — SQL-модель платформи та RLS.
- `docs/PLATFORM_ARCHITECTURE.md` — межі домену, модель даних і етапи.

Детальний стан і рішення мають синхронізуватися з AI_CONTEXT_HUB: `projects/multiplication-practice/`.
